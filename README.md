PriBrowser

A lightweight, open-source web browser project built with C#.

🚀 About

PriBrowser is an open-source browser project focused on being simple, lightweight, and easy to develop.

The source code is available so developers can:

- View the source code
- Modify the source code
- Fork the project
- Build their own browser based on PriBrowser
- Contribute improvements

🛠️ Build

PriBrowser can be built on Windows using the included GitHub Actions workflow.

The project uses:

- C#
- .NET
- GitHub Actions

The workflow automatically builds the Windows version and provides it as a downloadable artifact.

⚠️ Warning

PriBrowser is still in development. Builds may contain bugs or unfinished features.

Do not use development builds for sensitive or important browsing until you understand the risks.

Only download official releases from the official PriBrowser repository.

If you create your own browser based on PriBrowser, please use your own name, logo, and branding, and clearly identify it as an unofficial project.
